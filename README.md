# ProcessMonitoringTool

* 网络功能需要通过托盘图标进入设置里手动开启（注意，这可能会增加你的CPU占用，非必要不要开启）

### 一、采集能力（五项指标）

| 指标 | 数据源 | 口径 |
|---|---|---|
| CPU | `NtQuerySystemInformation` 差分 | 单核 100%，多核归一化到 100% |
| 内存 | 同上，Working Set | 字节 → 自动 MB/GB |
| 磁盘 | 同上，Read+Write 累计差分 | 读+写合计 B/s |
| 网络 | ETW `Microsoft-Windows-Kernel-Network` | TCP IPv4/IPv6 收发合计 B/s，默认关闭 |
| GPU | PDH `\GPU Engine(*)\Utilization Percentage` | 按 pid 聚合引擎利用率，0~100% |

- 采样在独立线程运行，默认 5 秒一次（可在设置里改，最小 1 秒）。
- GPU 按倍数降频（默认 2 倍），降低 PDH 调用开销。
- 网络启用后由独立 ETW 消费者线程实时累积，与主采样线程解耦。

### 二、排行榜窗口

- **半透明无边框悬浮窗**，背景透明、文字不透明，透明度 20%~100% 可调。
- 顶部五个 Tab 切换指标，每个 Tab 显示 Top N（默认 10，可设 5~20）。
- 每行显示：排名、程序名（多实例时带 `(N)`）、数值、**持续时间**。
- **持续时间语义**：该程序连续停留在当前指标 Top N 榜单里的时长，掉出即清零。
- **按路径聚合**：同一程序的多进程（Edge 各渲染器、QQ 各组件、svchost 各服务）合并为一行，按路径全称区分，不同目录的同名程序不会混淆。
- **已终止标记**：程序所有进程都退出后，最后一条记录灰显保留 30 秒（数值和时长冻结），最多显示 5 条，之后自动消失。
- **钉在桌面**：置顶 + 鼠标穿透（`WS_EX_TRANSPARENT`），窗口完全不可交互，**只能通过托盘菜单解锁**。
- 拖动移动、位置自动保存；缩放通过设置滑条调整（50%~200%）。

### 三、托盘与菜单

- **纯托盘常驻**，主窗口关闭 = 隐藏到托盘，不退出。
- 托盘左键/双击 = 显示窗口；右键菜单：
  - 历史统计 / 设置
  - 隐藏到托盘
  - 钉住桌面 / 解锁
  - 透明度 / 缩放（快速调节）
  - 退出

### 四、设置（`sysmonitor.ini`，程序目录）

- 语言：简体中文 / English
- 采样间隔：1~300 秒
- 榜单条数：5~20
- 历史保留：1~2160 小时（默认 48）
- GPU 采样倍数：1~20
- 启用网络统计（ETW）
- 过滤名单（按进程名关键字，每行一个）
- 透明度、缩放
- 开机自启（注册表 `Run` 项）

### 五、历史存储与统计

- **SQLite + WAL 模式**（`history.db`，程序目录），只存每轮 Top N + 指标 + 时间戳 + 路径。
- 5 秒批量事务落库，采样线程不碰磁盘。
- 保留期内自动清理过期记录。
- **统计窗口按需创建、关闭即释放**，不常驻内存。
- 时间范围精确到分钟，支持快捷按钮（最近 1h / 6h / 24h / 全部）。
- **热力图展示**：X 轴时间、Y 轴程序、颜色深浅 = 占用高低，一眼看出谁在何时飙高。
- **分块渐进加载**：每批 2 万条，边读边渲染，不会卡死 UI。

### 六、程序级约束

- **单实例**（`QLocalServer` 互斥），二次启动会唤醒已有实例。
- **强制管理员权限**（清单 `requireAdministrator`）——ETW、GPU 计数、部分进程的 IO 数据依赖此权限。
- 中英双语，运行时切换立即生效。
- C++17 / Qt 6.6 / MSVC / Windows 10/11 x64。

### 七、性能特征

- 空闲时约 0.2%~0.5% 单核占用、40~60 MB 内存。
- 主线程只做 UI，采集全部在独立线程。
- 进程路径按 `(pid, createTime)` 缓存，pid 复用时自动失效。
- 窗口隐藏到托盘后 UI 刷新几乎归零。

### 八、已知取舍

- **内存聚合偏大**：共享 DLL/页面被重复计入，工作集口径的固有问题。
- **网络默认关闭**：ETW 有额外常驻开销，用户按需启用。
- **stale 按 key（路径）去重**：同一个程序崩溃重启后，旧的 stale 记录会被新的活跃记录顶掉。
